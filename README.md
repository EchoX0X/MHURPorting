# MHURPorting

MHURPorting is a Windows asset-porting app for **My Hero Ultra Rumble**.

It gives you one place to browse the game's characters, costumes, animations, files, and installed mods, then export what you need to Blender, Unreal Engine, or a folder.

## What It Can Do

- **Character Browser:** Browse characters and costumes with visual previews.
- **Model Exporting:** Export character models with their skeletons, materials, and textures.
- **Animation Tools:** Browse, preview, and export character animations.
- **Blender Integration:** Send models and animations directly to Blender.
- **Game File Browser:** Browse the original game files without mixing them with mod files.
- **Mod Browser:** Browse each installed mod separately.
- **Mod Porter:** Port a packed character mod to another character or costume while keeping its included meshes, materials, textures, physics, animations, and file structure.
- **Automatic Updates:** Download updates from inside the app.

## Mod Porter

The Mod Porter changes the target character and costume paths inside a packed mod. This can be used to move a mod:

- **Character to Character:** Move a mod from one character to another.
- **Costume to Costume:** Move a mod between costumes belonging to the same character.
- **Preserved Content:** Keep the mod's compatible included content and file structure.

The app creates a new package and does not overwrite the source mod.

## Getting Started

1. Download `MHURPorting.zip` from the latest GitHub release.
2. Extract the whole ZIP to a normal folder.
3. Open `MHURPorting.exe`.
4. Select your **My Hero Ultra Rumble** installation when asked.
5. Open **Plugin** in the app to install or repair the Blender extension when using Blender exports.

Keep the extracted files together. Do not run the EXE from inside the ZIP.

## Requirements

- **Operating System:** Windows 10 or Windows 11, 64-bit.
- **Game:** An installed copy of My Hero Ultra Rumble.
- **Blender:** Optional and only required for direct Blender exports.
- **Unreal Engine:** Optional and only required for Unreal workflows.

## Updates

MHURPorting checks the official GitHub update file. When an update is available, a red indicator appears beside **Update** in the app. The existing installation updates in place; users do not need to download the app again for normal updates.
